# 🏆 نظام التعزيز والمكافآت للفصل
**Class Rewards & Motivation System**

> “كل إنجاز صغير يقود إلى نجاح كبير”

منصة عربية (RTL) لتحفيز الطلاب داخل الفصل: نقاط ونجوم، مستويات، شارات، متجر مكافآت، عجلة حظ، تحدي جماعي، مجموعات، وضع السبورة الذكية، تقارير، وشهادات قابلة للطباعة.

## التشغيل

```bash
npm install
npm run dev        # للتطوير: http://localhost:5173
npm run build      # بناء نسخة الإنتاج في dist/
npm run preview    # معاينة نسخة الإنتاج
```

مجلد `dist/` بعد البناء ملفات ثابتة تعمل على أي استضافة (يستخدم HashRouter و`base: './'`).

## أول تشغيل
- شاشة ترحيب ← إعداد الفصل (المعلم، المدرسة، الفصل، عدد/أسماء الطلاب).
- أو «جرّب النظام أولًا» لاستكشاف بيانات تجريبية (16 طالبًا بنقاط وشارات ومستويات)، ثم زر **«حذف البيانات التجريبية وبدء فصلي»**.

## المفاهيم
| الرمز | المعنى |
|---|---|
| ⭐ النجوم | مجموع النقاط المكتسبة مدى الحياة — تحدد المستوى ولا تنقص عند الاستبدال |
| 💎 النقاط | الرصيد القابل للصرف في متجر المكافآت |
| 🎁 المصروف | النقاط التي استُبدلت بمكافآت |

- الخصم **غير مفعّل افتراضيًا** (الإعدادات)، ويؤثر على الرصيد فقط ولا يُنزل المستوى.
- كل عملية (منح، خصم، استبدال، شارة، تراجع) تُسجَّل في سجل النشاط، ويمكن التراجع عنها (يُلغى معها ما ترتب عليها من شارات تلقائية أو ترقية مستوى).

## حفظ البيانات
- حفظ تلقائي في LocalStorage (المفتاح `class-rewards:state:v1`) — لا تضيع البيانات عند التحديث.
- الإعدادات ← 💾 تصدير / 📥 استيراد نسخة احتياطية بصيغة JSON.

## البنية
```
src/
  types/        أنواع TypeScript للبيانات
  data/         القيم الافتراضية والبيانات التجريبية
  services/     engine (منطق النقاط/الشارات/التراجع — دوال نقية)، stats، storage، sound (WebAudio)، confetti
  store/        AppStore (الحالة + الحفظ)، FxProvider (الاحتفالات، LEVEL UP، النقاط الطائرة)
  hooks/        useActions (عمليات المعلم + أصوات + Toast)، useStudentStats، useTheme
  components/   ui (أزرار، نوافذ، Toast، تأكيد…)، layout، students، charts، effects
  pages/        لوحة التحكم، الطلاب، ملف الطالب، الشارات، المتجر، العجلة، التحدي، المتصدرون،
                المجموعات، التقارير، الشهادات، الاحتفال، الإعدادات، وضع الفصل
```

التقنيات: React 19 · TypeScript · Tailwind CSS 4 · Vite · Recharts · lucide-react · canvas-confetti · خطوط Tajawal وBaloo Bhaijaan 2 (مضمّنة، تعمل دون إنترنت).
